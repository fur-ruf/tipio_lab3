# Функциональное тестирование интерфейса сайта с Selenium

## Изученные методы

- Функциональное тестирование — проверка того, что интерфейс сайта работает в соответствии с заявленными требованиями (кнопки нажимаются, формы отправляются, переходы работают).
- Use Case-моделирование — построение вариантов использования сайта (диаграмма прецедентов) как основы для создания тестового покрытия.
- Разработка CheckList тестового покрытия — систематизация проверок на основе прецедентов, чтобы ничего не упустить.
- Автоматизация тестирования через Selenium — использование Selenium IDE для записи шаблонов тестов и Selenium RC (Remote Control / WebDriver) для их исполнения.
- Кросс-браузерное тестирование — прогон одних и тех же сценариев в браузерах Firefox и Chrome для проверки совместимости.
- Поиск элементов через XPath — работа с динамически генерируемыми элементами страницы, когда ID ненадёжен или отсутствует.
- Тестирование на основе сценариев — описание набора тестовых сценариев (Test Cases), их выполнение и анализ результатов.

## Что реализовано

- Построена Use Case-диаграмма с прецедентами использования тестируемого сайта (в соответствии с вариантом задания).
- Сформирован CheckList тестового покрытия на основе набора прецедентов — все ключевые пользовательские сценарии покрыты проверками.
- Описаны тестовые сценарии (Test Cases) для каждого прецедента: предусловия, шаги, ожидаемый результат.
- Записаны шаблоны тестов в Selenium IDE с использованием XPath-локаторов для поиска элементов (так как сайт использует динамическую генерацию DOM).
- Тесты исполнены через Selenium RC / WebDriver в двух браузерах:
  1. Firefox — все сценарии отработали согласно ожиданиям;
  2. Chrome — все сценарии отработали согласно ожиданиям.
  3. Собраны результаты тестирования: зафиксировано прохождение тестов, отсутствие критичных расхождений между браузерами.
  4. Сделаны выводы о качестве интерфейса и корректности его работы в разных браузерах.
